## 一、常规麦克风检索与默认设备设置

通过 `pactl` 命令可查看系统音频输入 / 输出源，并配置默认麦克风，适用于 Linux/macOS 系统。

### 1.1 列出所有音频输入源（麦克风）及索引

查看系统已识别的所有麦克风设备，获取目标设备的索引（后续用于设置默认设备）：



```
\# 命令：列出输入源（麦克风），输出格式为“索引 设备名 驱动 格式 声道 采样率 状态”

pactl list sources short
```

输出示例：



```
0  alsa\_input.usb-Logitech\_USB\_Headset\_H570e-00.analog-mono  module-alsa-card.c  s16le 1ch 44100Hz  RUNNING

1  alsa\_input.builtin-microphone  module-alsa-card.c  s16le 2ch 48000Hz  IDLE
```

说明：`RUNNING` 表示当前正在使用的输入源，`IDLE` 表示闲置。

### 1.2 设置默认麦克风（输入源）

假设目标麦克风索引为 0（从步骤 1.1 获取），执行以下命令设置为默认输入设备：



```
\# 命令：将索引为0的输入源设为默认麦克风

pactl set-default-source 0
```

### 1.3 列出所有音频输出源及索引（可选）

若需同步配置默认扬声器（输出源），先查看输出设备列表：



```
\# 命令：列出输出源（扬声器/耳机）

pactl list sinks short
```

输出示例：



```
0  alsa\_output.builtin-speaker  module-alsa-card.c  s16le 2ch 48000Hz  RUNNING

1  alsa\_output.usb-Logitech\_USB\_Headset\_H570e-00.analog-stereo  module-alsa-card.c  s16le 2ch 44100Hz  IDLE
```

### 1.4 设置默认扬声器（输出源，可选）

假设目标输出源索引为 1，设置为默认扬声器：



```
\# 命令：将索引为1的输出源设为默认扬声器

pactl set-default-sink 1
```

### 1.5 重启 Pulseaudio 服务生效

配置后重启音频服务，确保设置生效：



```
\# 停止 Pulseaudio 服务

pulseaudio -k

\# 启动 Pulseaudio 服务（后台运行）

pulseaudio --start
```

### 1.6 验证配置是否成功

查看当前音频配置信息，确认默认输入 / 输出源是否正确：



```
\# 命令：查看音频系统信息

pactl info
```

关键验证项：



* `Default Source`：应显示步骤 1.2 设置的麦克风设备名

* `Default Sink`：应显示步骤 1.4 设置的扬声器设备名

## 二、Jetson NX 设备麦克风检索不到问题解决

针对 NVIDIA Jetson NX/Orin/Xavier 设备上 `sounddevice` 无法识别麦克风的问题，核心解决 PortAudio 对 PulseAudio 的支持问题。

### 2.1 文档适用范围



| 适用项  | 具体内容                                                       |
| ---- | ---------------------------------------------------------- |
| 设备型号 | NVIDIA Jetson Orin/Xavier NX、Jetson AGX Xavier、Jetson Nano |
| 系统环境 | Ubuntu 20.04/22.04 (aarch64 架构)                            |
| 涉及库  | PortAudio、Python sounddevice 库                             |
| 问题现象 | `sounddevice.query_hostapis()` 仅显示 ALSA/OSS，无 PulseAudio   |

### 2.2 问题背景

在 Jetson 设备上使用 `sounddevice` 库时，执行以下代码发现缺少 PulseAudio 支持：



```
import sounddevice as sd

print(sd.query\_hostapis())

\# 错误输出：\[{'name': 'ALSA'}, {'name': 'OSS'}] ❌ 无 PulseAudio
```

导致后果：



* 无法识别 USB 麦克风、蓝牙耳机等外部音频设备

* 无法使用 PulseAudio 管理的虚拟音频设备（如默认麦克风）

* 录音功能异常或无输入信号

### 2.3 根本原因分析



1. **系统自带 PortAudio 不完整**：Ubuntu 软件源的 `libportaudio2` 仅编译了 ALSA 支持，未启用 PulseAudio 后端，即使安装 `pulseaudio` 也无法生效。

2. **动态库优先级冲突**：用户编译的新版 PortAudio 安装在 `/usr/local/lib`，但 `sounddevice` 优先加载系统路径 `/usr/lib/aarch64-linux-gnu/` 下的旧库。

3. **符号链接指向静态旧文件**：系统路径下的 `libportaudio.so``.2` 实际指向静态旧文件 `libportaudio.so``.2.0.0`（通常为 2020 年前版本），替换链接无法生效。

### 2.4 解决方案总览



| 步骤 | 操作内容                                |
| -- | ----------------------------------- |
| 1  | 安装 PortAudio 编译依赖（含 PulseAudio 开发库） |
| 2  | 从源码编译支持 PulseAudio 的 PortAudio 库    |
| 3  | 替换系统旧 PortAudio 库，建立正确符号链接          |
| 4  | 验证 sounddevice 是否识别 PulseAudio      |
| 5  | 测试麦克风录音功能                           |

### 2.5 详细解决步骤

#### 步骤 1：安装编译依赖

必须安装 `libpulse-dev`（PulseAudio 开发库），否则无法启用 PulseAudio 支持：



```
\# 更新软件源并安装依赖

sudo apt update

sudo apt install -y build-essential autoconf libtool pkg-config

sudo apt install -y libasound2-dev libpulse-dev libsndio-dev liboss4-salsa-dev
```

#### 步骤 2：下载并编译 PortAudio 源码



```
\# 进入用户目录，克隆 PortAudio 仓库

cd \~

git clone https://github.com/PortAudio/portaudio.git

cd portaudio

\# 配置编译参数（启用 PulseAudio，禁用 JACK）

./configure --enable-pulse --with-pulse --disable-jack --prefix=/usr/local

\# 多线程编译（-j\$(nproc) 表示使用所有CPU核心）

make -j\$(nproc)

\# 安装到 /usr/local/lib 目录

sudo make install
```

验证编译结果：确认 PulseAudio 支持已启用：



```
cat config.log | grep -i pulse

\# 正确输出：checking for libpulse... yes
```

#### 步骤 3：替换系统旧库（关键步骤）

首先查看当前系统库状态：



```
ls -la /usr/lib/aarch64-linux-gnu/libportaudio\*
```

典型旧库输出（需替换）：



```
lrwxrwxrwx 1 root root     21 Mar 24  2020 libportaudio.so -> libportaudio.so.2.0.0

lrwxrwxrwx 1 root root     21 Oct 20 13:06 libportaudio.so.2 -> libportaudio.so.2.0.0

-rw-r--r-- 1 root root 187656 Mar 24  2020 libportaudio.so.2.0.0  # 静态旧文件
```

执行替换操作：



```
\# 1. 删除旧的静态文件 libportaudio.so.2.0.0

sudo rm /usr/lib/aarch64-linux-gnu/libportaudio.so.2.0.0

\# 2. 建立软链接，指向新编译的 PortAudio 库

sudo ln -s /usr/local/lib/libportaudio.so /usr/lib/aarch64-linux-gnu/libportaudio.so.2.0.0

\# 3. 修复 .so.2 和 .so 的符号链接，确保指向新库

sudo ln -sf libportaudio.so.2.0.0 /usr/lib/aarch64-linux-gnu/libportaudio.so.2

sudo ln -sf libportaudio.so.2.0.0 /usr/lib/aarch64-linux-gnu/libportaudio.so

\# 4. 刷新动态库缓存，使系统识别新库

sudo ldconfig
```

验证链接结果：



```
ls -la /usr/lib/aarch64-linux-gnu/libportaudio.so\*

\# 正确输出应显示所有链接指向 /usr/local/lib/libportaudio.so
```
